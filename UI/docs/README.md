# TTCS UI

A simple Python GUI application using Tkinter for TTCS UI.

## Setup

1. Ensure Python is installed (Tkinter is included by default in most Python installations).
2. Run the application: `python main.py`

## Usage

The app opens a window with a welcome message and a button. Click the button to show a message box.

## Troubleshooting

- If Tkinter is not available, install it: `pip install tk` (though usually built-in).
- Ensure Python version is 3.x.
